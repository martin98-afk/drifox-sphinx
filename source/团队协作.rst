团队协作
########

DriFox v0.3.3 引入完整的团队协作系统，支持多智能体协同工作；v0.4.9 全面升级，v0.5.2 起支持多团队并存。

核心概念
========

.. list-table::
   :header-rows: 1
   :widths: 20 50

   * - 概念
     - 说明
   * - Leader 智能体
     - 负责任务拆解、分发、监控进度和汇总结果
   * - 任务邮件系统
     - Agent 之间通过 ``team_send_message`` 异步收发任务；支持流式注入（v0.4.9）
   * - 多团队（TeamManager）
     - 多个团队并存管理，成员可跨团队复用（v0.5.2）
   * - 团队模板
     - 团队成员配置可保存为模板，由 system-team-templates 插件承载，加载模板完全新建窗口不劫持已有标签页（v0.4.11）
   * - 成员管理
     - ``team_manage`` 统一入口：list / create / add / remove / leave；群发仅 Leader；非成员也可向团队发消息（v0.6.14）

功能概览
========

- **Leader 智能体** — 专业统筹管理，自动将大任务拆解为子任务并分发给合适的 Agent
- **任务邮件** — ``team_send_message(to_agent, message)`` 向指定 Agent 发送任务，串行处理并自动开始；私聊任何成员可用，数组为群发（仅 Leader）
- **团队模板管理** — ``/team`` 命令支持模板保存/加载/列表/删除，带确认对话框防止误操作
- **团队会话持久化** — 会话携带团队元数据落库（run_id 注入），历史面板团队会话合并展示、一键恢复完整团队（v0.4.11）；恢复前自动解散现有团队
- **团队工作目录** — 团队共享工作目录管理与同步（v0.4.14）
- **权限与状态** — team tools 带权限检查（v0.4.9）；成员紧凑头像状态环展示运行状态（v0.6.11）
- **跨窗口协作** — 新增窗口自动排列，优化多窗口协作体验

使用方式
========

::

    /team save my-team          # 保存当前团队配置为模板
    /team load my-team          # 加载模板
    /team list                  # 列出所有模板
    /team delete my-team        # 删除模板
