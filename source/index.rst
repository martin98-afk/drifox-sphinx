DriFox |version_str|
####################

DriFox（飘狐）v0.3.9 是一款基于 Python + PyQt5 开发的**轻量化 AI 桌面对话助手**。不做大而全的 IDE，只是一个对话框——随时调出，随意提问，随性分支。

.. image:: _images/drifoxlogo.png
   :alt: DriFox Logo
   :align: center
   :width: 30%

.. image:: _images/drifoxtext.png
   :alt: DriFox
   :align: center
   :width: 60%

----

**核心理念**

- 🎯 **极简**：悬浮置顶对话框，随开随用
- 🔀 **分支**：问题分叉，多窗口并行探索
- 🧠 **记忆**：越用越懂你的偏好
- 🧩 **可扩展**：插件 / Agent / Skill / Hook / MCP 全方位扩展

----
