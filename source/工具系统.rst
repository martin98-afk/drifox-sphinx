工具系统
########

DriFox 提供 40+ 内置工具，覆盖文件操作、命令执行、网络访问、代码分析、桌面自动化、团队协作、插件市场管理等场景。自 v0.5.2 起工具系统全面插件化，由 system-tools 等系统插件承载。

========

   :header-rows: 1
   :widths: 15 60

   * - 类别

   * - 文件
     - read, write, edit, multi_edit, grep, glob, list, upload_file, open_file

   * - 网络

   * - 代码

   * - 记忆
     - memory_read, memory_write, recall_experience, record_experience
   * - 任务与调度
     - todowrite, todoread, skill, manage_skill, timer（定时/事件任务）
   * - 子智能体
     - subagent_para（并行分发）, subagent_status（状态查询）
   * - 团队
     - team_manage（list/create/add/remove/leave 统一分发）, team_send_message（任务邮件）

     - tool_search / tool_execute（按需发现并中转调用）、mcp_manage（临时开启已关闭的 MCP 服务器，v0.6.11）、``mcp__server__tool`` — 连接 MCP Server 后自动出现
   * - 插件市场

   * - 项目

   * - 交互
     - question

工具发展脉络
============

- ``codegraph_explore`` — 语义化代码探索（v0.3.4）
- ``team_manage`` / ``team_send_message`` — 团队协作（v0.3.3 引入，v0.5.2 起支持多团队 TeamManager）
- ``worktree-manager`` — Git 工作树管理工具，支持切换并自动变更会话工作目录（v0.5.11 引入，v0.6.12/0.6.15 增强）
- ``mcp_manage`` — MCP 管理器，模型可按需临时开启已关闭的服务器，用完关闭（v0.6.11）
- ``update_handoff`` — 会话接力交接，按六节结构落盘交接文档（v0.6.12）
- ``timer`` — 定时/事件任务调度，支持 queue/skip/hook 触发模式（v0.6.14）
- ``process.start`` — 插件能力面：后台进程启动，带进程台账与僵尸进程防治（v0.6.11）
