智能体系统
##################

.. image:: /_images/多子智能体任务执行.png
   :alt: 子智能体任务执行界面
   :align: center
   :width: 90%

DriFox 采用 **Primary / Subagent / Hidden** 三层 Agent 设计，通过 Markdown + YAML frontmatter 定义。

Agent 类型（内置 9 个，插件可扩展）
========================================

Primary Agent（3个）
----------------------------

拥有全部工具权限的主智能体：

- ``plan`` — 任务规划与分解（只读模式）
- ``build`` — 代码构建（全工具权限）
- ``code-reviewer`` — 代码审查

Subagent（4个）
----------------

可并行执行的子智能体，独立 LLM 循环 + 工具环境：

.. list-table::
   :header-rows: 1
   :widths: 25 50

   * - Agent
     - 说明
   * - explore
     - 代码库探索分析
   * - leader
     - 团队统筹管理（任务拆解/分发/监控/汇总）
   * - task-executor
     - 任务执行与工具调用
   * - review
     - 代码审查与反馈

Hidden Agent
------------

后台自动运行，无需用户感知：

- ``compaction`` — 上下文压缩
- ``title`` — 会话标题生成

.. note::

   自 v0.6.14 起子智能体系统由 system-subagent 插件承载（运行区、会话卡、管理与团队工具）；
   插件可通过贡献注册表动态新增 agent 定义，禁用插件时整组注销。

Agent 定义示例
==============

.. code-block:: yaml

    ---
    name: build
    mode: all
    temperature: 0.3
    permission:
      "*": allow
    ---

    # Role
    你是一个专业的 coding builder...

团队协作
========

v0.3.3 新增 **Leader 智能体**，负责统筹团队协作：

- ``team_manage`` — 团队统一管理入口（list / create / add / remove / leave）
- ``team_send_message`` — 向指定 Agent 发送任务邮件（串行处理，自动开始）
- ``/team`` 命令 — 团队模板的保存/加载/列表/删除
