桌宠系统
########

DriFox 内置的 PixelPet 桌面宠物系统，为用户提供情感化的交互反馈与状态可视化。

.. contents:: 目录
   :local:

设计哲学
========

桌宠不仅是装饰，更是一种 **情感化界面设计**。它将 AI 的工作状态转化为可感知、可视化的实体，让用户在等待 AI 思考时不再感到枯燥。我们相信：

- **状态可见** — 当 AI 在工作时，桌宠的动态让用户知道系统正在响应
- **情感连接** — 拟人化的宠物形象降低人机交互的冰冷感
- **轻量提醒** — 通过托盘图标变化传达重要状态变更

宠物状态与动画体系
===================

桌宠支持多种状态，每种状态对应独特的动画表现：

.. list-table::
   :header-rows: 1
   :widths: 20 40 40

   * - 状态
     - 动画描述
     - 触发场景
   * - 阅读
     - 专注查看书本的动画，持续循环
     - 用户发起阅读/分析任务时
   * - 休息
     - 打盹/放松的慵懒动画
     - 空闲超过指定时长后
   * - 思考
     - 眨眼/歪头的可爱动作
     - AI 正在处理请求时
   * - 等待
     - 站立/张望的静态动画
     - 等待用户输入时
   * - 运动
     - 行走/跳跃的动作序列
     - 任务完成庆祝时

行为管理机制
============

桌宠的行为由行为管理器统一调度，每个行为包含三个核心要素：

1. **动画片段** — 状态对应的视觉表现
2. **持续时长** — 行为维持的时间（可配置）
3. **状态转移** — 行为结束后的下一状态

阅读行为示例
------------

"阅读"行为是 v0.3 新增的核心行为，替代了旧版的"播放"概念：

.. code-block:: yaml

    behavior: 阅读
    animation: reading_book
    duration: 30s (可配置)
    next_state: 休息
    icon: 📖

行为可通过设置面板动态调整，用户可以自定义每个状态的持续时间与切换规则。

系统托盘集成
============

桌宠与系统托盘深度联动，实现多端状态同步：

- **托盘图标** — 实时反映桌宠当前状态（阅读/休息/思考）
- **右键菜单** — 快速切换桌宠状态或隐藏/显示桌宠
- **气泡通知** — 任务完成时通过托盘气泡提醒用户
- **最小化托管** — 主窗口隐藏时，桌宠保留在托盘区

托盘菜单选项：

- 显示/隐藏桌宠
- 切换至阅读模式
- 切换至休息模式
- 退出桌宠

端到端交互示例
==============

用户启动阅读任务时的完整流程：

1. 用户在对话框输入 "请阅读这个文件"
2. 系统派发任务给 AI 处理
3. 桌宠状态切换为 **阅读**，动画开始播放
4. 托盘图标同步变为阅读图标
5. AI 处理完成，桌宠切换为 **等待**
6. 如超过空闲阈值，自动切换为 **休息**

交互命令
========

用户可通过以下方式与桌宠交互：

- **设置面板** — 启用/禁用桌宠，调整行为参数
- **托盘菜单** — 快速切换状态
- **快捷键** — ``Ctrl+Shift+P`` 切换桌宠显示

配置项
======

.. code-block:: json

    {
      "pixelpet": {
        "enabled": true,
        "auto_start": true,
        "states": {
          "reading": { "duration": 30, "icon": "📖" },
          "resting": { "duration": 60, "icon": "💤" },
          "thinking": { "duration": 10, "icon": "🤔" }
        }
      }
    }

常见问题
========

**桌宠不显示？**

检查设置面板中是否已启用桌宠，并确认系统托盘区域未被任务栏隐藏。

**如何修改桌宠动画？**

当前版本不支持自定义动画，后续版本将开放主题市场。

**托盘图标不更新？**

尝试重启应用或检查系统托盘设置是否限制了图标更新。
