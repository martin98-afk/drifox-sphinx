团队协作
########

DriFox v0.3.3 引入完整的团队协作系统，支持多智能体协同工作。

核心概念
========

.. list-table::
   :header-rows: 1
   :widths: 20 50

   * - 概念
     - 说明
   * - Leader 智能体
     - 负责任务拆解、分发、监控进度和汇总结果
   * - 任务邮件系统
     - Agent 之间通过 ``team_send_message`` 异步收发任务
   * - 团队模板
     - 团队成员配置可保存为模板，支持加载/保存/列表/删除
   * - 团队成员列表
     - ``team_list_members`` 查看当前可用的所有 Agent

功能概览
========

- **Leader 智能体** — 专业统筹管理，自动将大任务拆解为子任务并分发给合适的 Agent
- **任务邮件** — ``team_send_message(to_agent, message)`` 向指定 Agent 发送任务，串行处理并自动回复
- **团队模板管理** — ``/team`` 命令支持模板保存/加载/列表/删除，带确认对话框防止误操作
- **跨窗口协作** — 新增窗口自动排列，优化多窗口协作体验

使用方式
========

::

    /team save my-team          # 保存当前团队配置为模板
    /team load my-team          # 加载模板
    /team list                  # 列出所有模板
    /team delete my-team        # 删除模板
