功能特性
========

- **组件级主题感知** — 所有 UI 组件（卡片、设置、tooltip 等）实现主题感知样式；主题刷新协调器统一调度（v0.4.8）
- **Pygments 语法高亮适配** — 代码高亮在深色/浅色主题下自动切换配色；搜索高亮色随主题（v0.6.14）
- **实时切换** — 切换主题无需重启应用，所有组件即时刷新；主题切换改为网格预览卡（v0.6.13）
- **统一 tooltip 字号管理** — 主题变更时同步刷新所有 tooltip
- **图标自适应** — 图标尺寸随系统字体大小自动缩放适配

使用方式
========

通过 ``/theme`` 命令或在设置面板中选择主题。

它不是什么
==========

- **不是 CSS 换肤** — 主题系统是组件级感知的，每个组件主动响应主题变更，而不只是全局 CSS 变量替换
- **不是重启生效** — 所有主题切换即时生效，无需重启应用
- **不是只有颜色** — 主题还控制字体大小、间距、图标尺寸等视觉参数

设计哲学
========

为什么 DriFox 要做 18 套主题，而不是简单的亮/暗切换？

1. **开发者审美是多元的** — 有人喜欢冷色深色（midnight），有人喜欢暖色深色（amber），有人喜欢浅色（pearl）——主题不是非黑即白
2. **主题影响效率** — 合适的配色减少视觉疲劳，代码高亮在不同主题下的可读性直接影响编码体验
3. **组件级感知** — 简单的 CSS 换肤会导致某些组件突兀，组件级感知确保每个 UI 元素都适配当前主题
4. **实时切换** — 开发者在白天和夜晚可能需要不同的主题，实时切换让这种转换自然无感
